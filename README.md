# ArcSpace — Landing Page

Sitio web promocional de **ArcSpace: Observatorio Estelar Arcade**, un videojuego educativo interactivo que fusiona mecánicas arcade con divulgación científica astronómica, desarrollado como proyecto institucional para la **Tecnicatura Superior en Desarrollo de Software**.

## Acerca del proyecto

Esta landing page presenta el juego ArcSpace, su versión original en Python/Pygame y su adaptación web. El sitio está diseñado con una estética de cómic/Marvel —tipografías Bangers y Luckiest Guy, onomatopeyas flotantes, cards con clip-path, halftone patterns— y funciona como página única con secciones informativas y una galería de capturas.

## Secciones

- **Hero** — Portada con título, descripción y CTAs
- **¿Qué es?** — Descripción del proyecto y su enfoque pedagógico
- **Características** — Detalles técnicos del juego original
- **Versión Web** — Comparativa y enlace para jugar
- **Galería** — Carrusel de capturas de pantalla
- **Tecnologías** — Stack utilizado

## Tecnologías

- HTML5
- CSS3 (diseño responsive, animaciones, estética comic)
- JavaScript (partículas, carrusel, scroll effects, navegación)
